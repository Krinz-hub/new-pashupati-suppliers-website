# 6. HOW TO TAKE THE PHOTOS (Photographer's Guide)

Follow these rules when capturing photos on a smartphone (iPhone / Samsung / modern Android) or DSLR:

1. **Clean the Camera Lens:** Always wipe the smartphone camera glass with a microfiber cloth before shooting.
2. **Use Native Main Lens (1×):** Do not pinch-to-zoom digitally. Walk closer to the subject to preserve crisp resolution.
3. **Turn On All Store Lighting:** Turn on all ceiling tubes, LED panels, and display spotlights. Open front shutters for natural daylight.
4. **Organize Shelves First:** Spend 10 minutes facing all product labels forward, straightening stacks, and dusting shiny surfaces.
5. **Clear Floor Clutter:** Remove dustpans, empty water bottles, packing tape rolls, and personal items from the camera frame.
6. **Keep Level Horizons:** Keep vertical shelf lines straight and parallel. Use grid lines on your phone camera.
7. **Shoot in Native High Resolution:** Capture in full 12MP/48MP/RAW without third-party camera apps.
8. **No Filters or Heavy Post-Processing:** Do not apply Instagram or beauty filters. Keep true-to-life colors.
9. **Never Use WhatsApp for File Transfer:** Transfer photos via Google Drive, AirDrop, or USB to prevent compression artifacts.
10. **Take 3 Variations of Each Shot:** Take one eye-level, one slightly higher, and one closer shot so the best composition can be chosen.

# 10. Environment Configuration

All environment-specific and business configuration variables are centralized in the root [`.env`](file:///Users/dev/new%20pashupati%20suppliers/.env) file.

### Environment Variable Guidelines
- **File Location:** The `.env` file resides in the root project directory (alongside `package.json`, `vite.config.ts`, `src/`, and `public/`).
- **Client-Side Visibility:** Because this is a Vite Single Page Application (SPA), all variables prefixed with `VITE_` are embedded into the client-side JavaScript bundle during build and are **publicly visible in the browser**.
- **Security Rule:** **NEVER** store private secrets, database passwords, email account passwords, or private API keys in `.env`.
- **Git Protection:** The `.env` file is excluded in `.gitignore` to prevent committing local configurations.
- **Template File:** A safe template file [`.env.example`](file:///Users/dev/new%20pashupati%20suppliers/.env.example) is committed to Git to allow new developers or deployment servers to quickly configure their environment.
