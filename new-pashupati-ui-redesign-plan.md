# New Pashupati Suppliers — UI Redesign Plan

## Goal

Redesign the website so it feels:

- Clean and intentional
- Less repetitive
- Easier to scan
- More premium and natural
- Visually driven instead of card-heavy
- Consistent across desktop, tablet, and mobile

Do **not** completely change the existing brand identity. Keep the dark navy and orange-red accent system, but use them with more restraint.

---

# Phase 1 — Fix Global Layout

## 1. Establish a consistent spacing system

The current pages have inconsistent vertical gaps. Some sections feel compressed while other areas have excessive empty space.

Use a consistent spacing scale:

- 8px — tiny gaps
- 16px — small gaps
- 24px — standard component spacing
- 32px — large component spacing
- 48px — section content spacing
- 80–120px — desktop section spacing

### Rules

- Every page should use the same max-width container.
- Align hero content, section headings, grids, and footer content to the same container edges.
- Avoid adding large empty areas simply to fill the viewport.
- Let content determine section height.

---

# Phase 2 — Simplify Navigation

## Problem

The navigation currently contains too many equally important items:

- Home
- About Us
- Our Products
- Wholesale
- Portfolio
- Contact Us

This creates visual competition and makes the header feel more like a dashboard.

## Solution

Use:

- Home
- Products
- Wholesale
- About
- Contact

Move the portfolio/store gallery into a section inside the About page or Home page unless it is important enough to justify its own page.

### Header improvements

- Keep the logo on the left.
- Keep navigation centered or aligned naturally after the logo.
- Keep only one strong CTA: `Get in Touch`.
- Remove duplicate phone-number buttons from the navbar if the CTA already leads to contact.
- On mobile, collapse navigation into a clean menu.
- Avoid giving every navigation item a border, pill, or heavy active state.
- Use a subtle underline or accent line for the active page.

---

# Phase 3 — Rebuild the Homepage Hierarchy

The homepage currently repeats similar concepts through multiple card grids.

Recommended structure:

1. Header
2. Hero
3. Key trust indicators
4. Product categories
5. Why choose us
6. Wholesale CTA
7. Store/gallery preview
8. Contact CTA
9. Footer

## Remove or reduce

Do not repeat:

- Multiple large product card sections
- Similar feature grids with nearly identical cards
- Multiple CTA sections saying the same thing
- Store/gallery cards that look identical to product cards

Each section must answer a different question.

---

# Phase 4 — Improve the Hero

## Current problem

The hero can feel like text placed beside a decorative box or image card.

## New approach

Use the product/store visual as part of the hero composition.

### Requirements

- Use the image or video as a background or integrated visual layer.
- Do not place it inside an unnecessary floating card.
- Add a subtle gradient overlay only where needed for text readability.
- Keep the text area clean and readable.
- Make one CTA primary.
- Make secondary actions visually quieter.

### Recommended content

**Headline:**
`Everything Your Business and Home Needs`

**Supporting text:**
One concise paragraph explaining household, kitchen, plastic, electrical, cleaning, storage, and general supplies.

**Primary CTA:**
`Explore Products`

**Secondary CTA:**
`Contact Us`

Avoid excessive badges, pills, icons, and decorative labels.

---

# Phase 5 — Product Categories

## Current problem

Product cards and portfolio cards are visually too similar.

## Solution

Use a dedicated category layout.

### Desktop

- 3 columns × 2 rows
- Use real product/category images where available
- Category name
- Short one-line description
- Optional subtle arrow

### Example categories

- Kitchen Supplies
- Household Supplies
- Plastic Supplies
- Electrical Supplies
- Cleaning Supplies
- Storage Supplies

### Visual rules

- Do not put an icon inside every card if a real image is available.
- Use a single consistent image ratio.
- Avoid heavy borders and excessive shadows.
- Hover effects should be subtle.

---

# Phase 6 — Merge Repetitive Trust Sections

Currently concepts such as:

- Quality
- Trust
- Reliability
- Customer Focus
- Fair Pricing
- Continuous Improvement

are presented in many similar cards.

## Solution

Keep one `Why Choose Us` section.

Use only 3–4 strongest reasons:

1. Wide Product Range
2. Reliable Supply
3. Fair Wholesale Pricing
4. Friendly Local Service

Use either:

- A simple 2×2 grid, or
- A horizontal feature layout

Do not create another separate values grid with the same card design unless the About page specifically needs it.

---

# Phase 7 — Improve the About Page

Recommended structure:

1. Simple hero
2. Store photo/video with company story
3. Key statistics
4. Mission + Vision
5. Core values, only if necessary
6. Final CTA

## Important

Do not show:

- Statistics
- Mission cards
- Vision cards
- Values cards
- Benefits cards

all with the same white rounded rectangle design.

Create visual variation through layout, typography, imagery, and spacing rather than constantly adding cards.

---

# Phase 8 — Portfolio / Store Gallery

## Current problem

The gallery cards currently look almost identical to product cards.

## Solution

Make the gallery image-first.

Each gallery item should contain:

- Large real image
- Small category label
- Short title

Use:

- Masonry-style grid, or
- Clean asymmetric grid

Do not create fake placeholder illustrations when real store images exist.

The gallery should feel like a visual tour, not another product catalog.

---

# Phase 9 — Wholesale Page

The current page has too much empty vertical space.

## Recommended structure

1. Compact hero
2. Wholesale benefits
3. Simple inquiry process
4. CTA/contact form

### Wholesale benefits

Use 3 points:

- Bulk quantities
- Competitive pricing
- Reliable coordination

### Inquiry process

Show a simple 3-step horizontal flow:

`Tell Us What You Need → Receive Quote → Confirm & Arrange Supply`

Avoid another large collection of feature cards.

---

# Phase 10 — Contact Page

The contact page is generally useful but can be simplified.

## Recommended layout

Left:

- Short introduction
- Phone
- WhatsApp
- Email
- Address
- Opening hours

Right:

- Inquiry form

### Improvements

- Remove unnecessary nested cards.
- Group related contact information naturally.
- Make WhatsApp a clear secondary action.
- Keep the form clean with enough spacing.
- Use fewer borders.

---

# Phase 11 — Footer Simplification

The footer currently repeats a lot of navigation and category information.

Use four areas:

1. Brand + short description
2. Navigation
3. Product categories
4. Contact information

### Remove

- Unnecessary duplicate links
- Too many social buttons if they are not active
- Repeated calls to action

Keep the footer compact enough that it feels like the end of the website rather than another full section.

---

# Phase 12 — Visual Design Cleanup

## Reduce card dependency

Do not put everything inside:

- Rounded rectangles
- Borders
- Shadows
- Pills
- Floating containers

Use cards only when grouping information genuinely improves readability.

## Border radius

Use a small, consistent radius system.

Suggested:

- 8px for small controls
- 12px for cards
- 16px for large image containers

Avoid different random radius values across sections.

## Shadows

Use very subtle shadows.

Avoid:

- Heavy glowing shadows
- Shadows on every element
- Multiple shadow layers

## Backgrounds

Use mostly clean backgrounds with subtle tonal changes between major sections.

Example:

- Main background: warm white/light gray
- Alternate section: very subtle gray
- Dark sections: navy

Do not use decorative gradients everywhere.

---

# Phase 13 — Typography

Create a clear hierarchy.

## Headings

- Large and bold
- Limited line length
- Avoid unnecessarily huge headings

## Body text

- Comfortable line-height
- Maximum readable width
- Avoid long paragraphs across the entire page

## Labels

Use small accent labels sparingly.

Do not place a pill-shaped label above every single section. This pattern is currently repetitive.

Use section labels only when they add hierarchy.

---

# Phase 14 — Buttons

Use only three button styles.

## Primary

Orange-red filled button.

Used for the most important action.

## Secondary

Navy outline or subtle filled button.

## Text link

Simple text with arrow.

Do not create a unique button style for every section.

---

# Phase 15 — Animations

Create one consistent animation system for the entire website.

## On-scroll

Use subtle:

- Fade up
- Fade in
- Small translate Y

Suggested values:

- Duration: 0.5–0.7s
- Translate: 12–24px
- Ease: smooth ease-out

## Stagger

Cards in a grid can appear with a small stagger.

Do not animate every element aggressively.

## Hover

Use only:

- Slight upward movement
- Small image zoom
- Border/accent change

Avoid:

- Excessive bouncing
- Spinning
- Large scaling
- Different animation styles on every section

All animations should feel like part of one design system.

---

# Phase 16 — Responsive Design

## Desktop

- Use spacious two-column layouts.
- Keep content inside a consistent max-width.
- Do not stretch cards unnecessarily.

## Tablet

- Reduce multi-column grids gradually.
- Use 2-column layouts where appropriate.
- Adjust heading sizes.

## Mobile

Prioritize:

- Single-column flow
- Large tap targets
- Readable text
- Reduced decorative elements

### Mobile rules

- Avoid forcing desktop card layouts onto small screens.
- Do not leave massive empty vertical sections.
- Stack hero content naturally.
- Keep the most important CTA visible.
- Product grids should become 2 columns or 1 column depending on content.
- Horizontal overflow must never occur.

---

# Final Design Rules

Before accepting any section, check:

1. Does this section have a unique purpose?
2. Is this information already shown elsewhere?
3. Does this need a card?
4. Does this need an icon?
5. Does this need a badge?
6. Does this need another CTA?
7. Can this section be simpler?
8. Does it look consistent with the rest of the website?

## Final target

The finished website should feel:

**Simple → Clear → Trustworthy → Premium**

Not:

**Card-heavy → Repetitive → Over-decorated → Cluttered**

The goal is to make New Pashupati Suppliers feel like a real, established local supplier with a professional modern website—not a generic template made from repeated UI cards.
